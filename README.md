# Excavando en Pampa de Altura

Juego de excavación arqueológica en primera persona en un alero de granito de Pampa de Achala (Sierras Grandes de Córdoba, Argentina). Se juega en el navegador.

**Jugar:** abrí la página publicada de este repositorio (Settings → Pages).

- Calidad gráfica: agregá `?q=low` al final del enlace en equipos modestos o `?q=high` en compus con buena placa de video.
- Controles: W A S D para caminar, mouse para mirar, clic para usar, 1–5 herramientas, L libreta, V colección. En celular: joystick y botón Usar.

## Créditos

- Sitio ficticio con fines didácticos.
- Fotografías de puntas óseas, hematita y adornos: Rivero et al. (2024).
- Motor 3D: [three.js](https://threejs.org) (MIT). PDF: [jsPDF](https://github.com/parallax/jsPDF) (MIT).
- Manos: modelos genéricos de WebXR (MIT).
